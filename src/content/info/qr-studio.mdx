# QR Studio

Een QR-code is een leesbare verwijzing. Ontwerp en bestemming zijn afzonderlijke keuzes: een mooi patroon moet nog steeds betrouwbaar scanbaar zijn.

## Ontwerpen op je apparaat

De generator tekent de QR-code lokaal. Kies je inhoud, stijl en contrast, en bekijk de code voordat je exporteert. On-device Smart Labels kunnen de gekozen inhoud begeleiden zonder dat daarvoor een externe AI-dienst nodig is.

## Statisch of dynamisch

Een statische code bevat rechtstreeks de gekozen inhoud. Die verandert niet nadat je hem afdrukt. Een dynamische code bevat een beheerde link: de bestemming wordt door de dienst afgehandeld en vereist een werkende deployment.

<Callout type="warning" title="Een beheerde link blijft afhankelijk van hosting">Een lokaal gemaakte afbeelding werkt niet als vervanging voor de server achter een dynamische bestemming. Controleer het echte adres voor je publiceert.</Callout>

## SVG en afbeeldingen

SVG is geschikt voor schaalbare vectorweergave. Een rasterexport is handig voor documenten en berichten. Canvas is een tekenmethode, geen aparte garantie over kwaliteit: het formaat, de rand rond de code en het contrast bepalen mee of scanners hem kunnen lezen.

## Van scherm naar drukwerk

Test de export met meerdere telefoons en op de grootte waarop je hem gaat gebruiken. Behoud een rustige vrije rand, vermijd te laag contrast en laat een logo de code niet onleesbaar maken. Controleer ook de bestemming na het scannen.

## Je profielcode bewaren

Bewaar je ontwerp vanuit de actieve generator en controleer het gepubliceerde profiel. Delen gebruikt de opgeslagen instellingen; een niet-bewaarde wijziging is geen nieuwe publieke versie.
